Build a complete, self-contained web application called "GestureForge 3D" — 
a professional 3D modeling platform with real-time hand gesture control via webcam. 
The app must run with `pnpm install` and `pnpm run dev`, using React + Vite (frontend) 
and Express (backend), fully independent of Replit — no Replit-specific APIs, 
no external paid services, all logic self-hosted.

CORE FEATURE 2 — HAND GESTURE CONTROL (MEDIAPIPE)
───────────────────────────────────────────────
Webcam feed processed by @mediapipe/hands (21 landmarks per hand, 
both hands simultaneously). Render a small semi-transparent webcam 
overlay in the bottom-right corner showing skeleton landmarks.

Gesture detection engine:
  Build a GestureRecognizer class that:
  - Runs at 30fps in a Web Worker or requestAnimationFrame loop
  - Detects finger states (extended/curled) for all 5 fingers
  - Computes pinch distance (thumb tip ↔ index tip)
  - Computes palm normal vector
  - Computes fist closure percentage
  - Tracks two-hand distance and relative position
  - Has configurable sensitivity thresholds per gesture
  - Includes cooldown timers to prevent gesture spam

Implement ALL of these named gestures:

ONE-HAND GESTURES:
  1. PINCH_GRAB — thumb + index pinch → grab/select object under cursor
  2. PINCH_DRAG — pinch while moving hand → translate selected object (XY plane)
  3. PINCH_LIFT — pinch + raise hand → translate object on Z axis
  4. FIST_ROTATE — closed fist + rotate wrist → rotate object on Y axis
  5. OPEN_PALM_SCALE_UP — open palm moving away from camera → scale up object
  6. OPEN_PALM_SCALE_DOWN — open palm moving toward camera → scale down object
  7. POINT_SELECT — only index extended → raycast select object
  8. POINT_DRAW — index extended + wrist moving → draw spline curve in 3D space
  9. PEACE_SIGN — index + middle extended → toggle vertex edit mode
  10. THREE_FINGERS — index + middle + ring → toggle edge selection mode
  11. FOUR_FINGERS — all except thumb → toggle face selection mode
  12. THUMB_UP — fist + thumb extended up → confirm/apply operation
  13. THUMB_DOWN — fist + thumb extended down → undo last operation
  14. PINCH_TWIST — pinch + forearm rotation → rotate object on Z axis
  15. SPREAD_FINGERS — all 5 fingers extended, spreading → extrude selected face
  16. CLAW_DEFORM — fingers half-curled, moving → soft-body deform mesh vertices near cursor
  17. KNIFE_HAND — flat palm, fingers together, horizontal → slice/cut geometry
  18. INDEX_CIRCLE — index tip traces circle → create loop cut on mesh
  19. WRIST_FLICK — fast wrist snap → throw/launch physics object
  20. PALM_PUSH — palm facing camera, push forward → apply explosion force to nearby objects

TWO-HAND GESTURES:
  21. BIMANUAL_PINCH_SCALE — both hands pinch, move apart/together → uniform scale
  22. BIMANUAL_ROTATE — both hands pinch, arc motion → rotate object in 3D space
  23. BIMANUAL_STRETCH — both pinch on same object, pull apart → non-uniform stretch (X axis)
  24. BIMANUAL_SQUISH — both pinch, push together → squish deformation (Y axis compression)
  25. BIMANUAL_TWIST — both pinch, counter-rotate → twist deformation along axis
  26. BIMANUAL_FRAME — both index fingers form rectangle → crop/frame viewport or create plane
  27. CONDUCTOR_WAVE — both open palms, wave motion → global elastic wave simulation on all objects
  28. PRAYER_HANDS — palms together, fingers up → freeze/unfreeze physics simulation
  29. CLAP — both palms clap → reset scene to last saved state
  30. BIMANUAL_PORTAL — both index+thumb form circles → create QR anchor point at cursor position

Gesture feedback system:
  - Floating gesture name badge (shows detected gesture for 1.5s)
  - Animated hand skeleton overlay on webcam feed (color-coded by gesture)
  - Configurable gesture sensitivity panel (sliders per gesture)
  - Gesture assignment panel: user can remap gestures to different functions

CORE FEATURE 3 — PHYSICS ENGINE (RAPIER)
───────────────────────────────────────────────
Use @react-three/rapier for real physics:

- Toggle physics simulation on/off per object
- Rigid body types: Dynamic, Kinematic, Fixed
- Collider types: Auto-fit, Box, Sphere, Capsule, Convex Hull, Trimesh
- Physics properties panel per object:
    mass, restitution (bounciness), friction, 
    linear damping, angular damping, gravity scale
- Elastic/soft-body simulation:
    Implement spring-mass soft body approximation:
    subdivide mesh → connect vertices with spring joints →
    simulate compression/stretch with configurable:
      stiffness (0.0–1.0)
      damping (0.0–1.0)  
      rest length multiplier
- Cloth simulation mode (plane mesh with pinned vertices + wind force)
- Global forces panel: gravity direction+magnitude, wind (direction + turbulence), 
  explosion (point + radius + force)
- Physics debugger: toggle wireframe collider visualization
- Slow-motion toggle (timeScale 0.1×)

CORE FEATURE 4 — QR REFERENCE POINTS (myWebAR-style)
───────────────────────────────────────────────
Express backend provides:

POST /api/anchors — create anchor { id, name, position, rotation, scale, modelData }
GET /api/anchors — list all anchors
GET /api/anchors/:id — get anchor details
DELETE /api/anchors/:id — remove anchor

Frontend QR system:
  - "Create QR Anchor" button in toolbar
  - User names the anchor and positions it in 3D scene
  - Server saves anchor data (JSON file persistence, no DB required)
  - Client generates QR code (using `qrcode` library) encoding URL:
      http://localhost:5173/anchor/:id
  - QR is displayed in a modal with download button (PNG export)
  - /anchor/:id route loads the scene with that anchor's model pre-loaded
  - Anchor viewer page shows the 3D model with orbit controls
  - Anchors panel: list all saved anchors, click to teleport camera to anchor position
  - Anchors appear in 3D scene as glowing marker pyramids with labels
  - Export anchor pack: ZIP containing QR image + GLTF model + manifest JSON

PERFORMANCE REQUIREMENTS
───────────────────────────────────────────────
- MediaPipe runs in requestAnimationFrame, throttled to 30fps max
- Three.js scene targets 60fps; auto-downscales pixel ratio on low-end devices
- React renders isolated from Three.js loop (no re-render on every frame)
- Zustand stores: separate stores for scene, gestures, UI, physics
- Web Worker for gesture processing (if SharedArrayBuffer available)
- Lazy-load heavy libs (Rapier WASM, MediaPipe models) with loading progress
- Vite chunk splitting: vendor, three, mediapipe, rapier as separate chunks
- Service Worker for caching MediaPipe model files (avoid re-download)
